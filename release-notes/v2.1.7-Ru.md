## Список изменений (Changelog)

> После удаления «Шёпота» в v2.1.5 эта версия реализует его заново с **семантикой десктопного клиента**; нативная библиотека синхронно обновлена до сборки с интерфейсом шёпота (патч приложен к репозиторию, воспроизводимо).

### 💬 Шёпот / Тайные сообщения (Whisper)
- **Отправка только при удержании кнопки шёпота**: слева от основного микрофона в нижней панели добавлен **янтарный микрофон шёпота** (со значком шёпота), есть он и в панели плавающего окна. При удержании микрофон отправляет звук только целям из списка шёпота, при отпускании немедленно возвращается к разговору в канале — без необходимости предварительно переключать какой-либо режим
- **Без обрезания начала фразы**: при нажатии сначала переключается маршрут, микрофон включается только после того, как нативный набор целей готов; при отпускании сначала выключается микрофон, затем снимается маршрут. Режим микрофона до нажатия (удержание для разговора / голосовая активация / открытый микрофон) восстанавливается как был
- **Групповой шёпот на сервере идёт через нативную маршрутизацию протокола**: по протоколу TS3 1.8.2.1 отправляется пакет группового шёпота (`VoiceWhisper` + `Newprotocol` + `GroupWhisperType::ServerGroup`), состав группы разбирает сервер. **Группа считается за одну цель**, участники, присоединившиеся к группе позже, тоже сразу слышат — раскрывать в клиентский список не нужно
- **Редактор списка шёпота** (иконка шёпота в верхней панели): три раздела с чекбоксами — серверные группы / каналы / участники, имена групп берутся из `servergrouplist` сервера, в строке группы отображается число онлайн; кнопка справа в строке участника, панель по долгому нажатию на участника и долгое нажатие на строку канала позволяют сразу добавить / убрать
- Цели архивируются по **UID**, после автоматического переподключения при обрыве список автоматически рассылается заново; когда все цели офлайн, голос отбрасывается, а не откатывается к широковещанию в канал; введённый текст отправляется личными сообщениями той же группе адресатов
- Когда кто-то шепчет вам, аватары участников и пузырь плавающего окна становятся **янтарными**, и один раз показывается подсказка (защита от повторов 15 секунд)

### 👥 Информация об участниках
- **Долгое нажатие на любого участника (включая себя)**: панель показывает его **серверные группы** и **канальные группы**, имена групп берутся из `servergrouplist` / `channelgrouplist` сервера; если имя группы не получено — откат к `#id`; при большом числе групп этот раздел прокручивается отдельно
- В своей строке отображаются только идентификация и информация о группах, операции «бессмысленные для себя» — громкость / отключение звука / личные сообщения / шёпот — скрываются

### 🚪 Каналы
- **Каналы с паролем**: в строке канала отображается иконка замка, по нажатию открывается поле ввода пароля (в плавающем окне — встроенный ввод, поскольку плавающее окно имеет `WRAP_CONTENT` и полноэкранный диалог был бы обрезан), после подтверждения вход выполняется с паролем, больше нет «нажал — и ничего не происходит»; пароль не сохраняется
- **Смена временного никнейма в канале**: долгое нажатие на себя → «Изменить временный никнейм», через `clientupdate client_nickname` применяется сразу; действует только для текущего соединения, не записывается в файл идентификации, после переподключения восстанавливается никнейм, использованный при подключении

### 🔧 Низкий уровень
- Нативная библиотека собрана **самостоятельной кросс-компиляцией на основе `tslib_multi` 8e0bc11 с патчем**, патч приложен к репозиторию (`patches/tslib_multi-8e0bc11-whisper-groups.patch`) и чисто применяется к этому коммиту
- Исправлены два расхождения сигнатур JNI: в `nativeMoveToChannel` добавлен параметр пароля канала, в `OpusCodec.nativeDecode` добавлен параметр FEC
- Приём голоса переведён на **push-колбэк** (это единственное место, где можно отличить «пакет шёпота» от «пакета канала»), событийный путь воспроизведения `audio_received` удалён во избежание двойного воспроизведения
- Модульные тесты **46 → 75**; на стороне `tslib` дополнительно 60 модульных тестов на Rust (включая зафиксированную по документации протокола байтовую раскладку пакета группового шёпота)

### 🐛 Исправление ошибок
- Исправлена подсказка «список пуст» при удержании микрофона шёпота, когда список шёпота не пуст: колбэк жеста держал устаревшее состояние с первой композиции
- Исправлено отсутствие реакции на нажатие канала с паролем (ранее не было никакого входа для пароля, после отказа сервера интерфейс не показывал подсказку)
- Исправлен молчаливый сбой списка каналов плавающего окна для каналов с паролем (заменено на встроенный ввод пароля)

### ⚠️ Внимание
- Непустой список шёпота **не** делает микрофон постоянно в режиме шёпота — нужно удерживать кнопку шёпота; текстовые сообщения из списка по-прежнему отправляются той же группе адресатов
- Верхний предел записей целей шёпота — 10 (значение по умолчанию `virtualserver_maxwhisperclients` сервера), клиент / канал / пользовательская группа считаются каждая за одну запись
- Данная нативная библиотека собрана для **arm64**, поддерживаются только 64-битные arm-устройства (Android 8.0+)
