## Список изменений (Changelog)

> Добавлено меню «Статус» как в десктопном клиенте (онлайн / отошёл / не беспокоить), а также исправлены две проблемы: статус не отображался у других, и в плавающем окне нельзя было ввести пароль.

### 🟢 Статус (онлайн / отошёл / не беспокоить)
- В крайней левой части нижней панели добавлен **индикатор статуса** (зелёный = онлайн, янтарный = отошёл, красный = не беспокоить), по нажатию открывается меню статуса; в панели по долгому нажатию на свою строку тоже есть пункт «Изменить статус»
- **Онлайн**: снимаются отметка «отошёл» и сообщение об отсутствии
- **Отошёл**: устанавливаются отметка «отошёл» и сообщение об отсутствии, микрофон работает как обычно
- **Не беспокоить**: помимо отметки «отошёл» **микрофон отключается**, удержание для разговора / удержание для шёпота / открытый микрофон не могут включить микрофон; при переключении обратно в онлайн или «отошёл» микрофон восстанавливается согласно текущему режиму
- **Пользовательское сообщение об отсутствии**: заполняется прямо в меню (до 100 символов), при пустом поле используется текст по умолчанию (отошёл / не беспокоить)
- После переподключения при обрыве выбранный статус автоматически восстанавливается, сбрасывается в онлайн только при активном отключении

### 👥 Статус участников
- В панель по долгому нажатию на любого участника добавлены две строки — «Статус» и «Сообщение об отсутствии»; в списке участников у отошедших имя тускнеет и появляется значок луны

### 🐛 Исправления
- **Переключение статуса не отображалось у других клиентов**: при переключении статуса отправлялась только одна команда, быстрые нажатия объединялись, между командами выдерживался минимальный интервал, больше не срабатывает ограничение сервера от флуда (`client is flooding`) с потерей команды; если всё же сработало ограничение, через 10 секунд команда автоматически отправляется повторно
- **В плавающем окне нельзя было ввести пароль для канала с паролем**: при открытии поля пароля окну временно разрешается получить фокус и показать клавиатуру, после закрытия сразу восстанавливается
- **Состояние отключения микрофона**: сообщается только при реальном изменении состояния и использует тот же минимальный интервал, что и команды статуса, поэтому быстрое удержание / отпускание для разговора тоже не вызывает ограничения от флуда

### 🔧 Низкий уровень
- Нативная библиотека собрана самостоятельной кросс-компиляцией на основе `tslib_multi` 8e0bc11 с патчем, добавлен новый патч `patches/tslib_multi-8e0bc11-away-status.patch` (накладывается поверх патча шёпота из v2.1.7)
- В `tslib-core` добавлен `set_away`, в `tslib-jni` добавлен `nativeSetAway` (arm64-v8a, `--features vendored-openssl`)
- Модульные тесты **75 → 79**

### ⚠️ Внимание
- Отключение микрофона в «Не беспокоить» — локальное поведение, другие клиенты видят только отметку «отошёл» и сообщение об отсутствии
- Сообщение об отсутствии — до 100 символов
- Данная нативная библиотека собрана для **arm64**, поддерживаются только 64-битные arm-устройства (Android 8.0+)
